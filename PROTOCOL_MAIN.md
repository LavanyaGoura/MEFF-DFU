# MEFF v3 — Pre-registered protocol (revision R1)

Written on 29 Oct 2026 and revised on 1 Nov 2026, before any full v3 training run. Revision R1 changes the split from near-duplicate-aware to an image-level stratified random split, at the authors' request. Everything else is unchanged.

Do not edit this file after training starts. `meff_v3.py eval` records this file's MD5 in `results/eval_meta.json`.

## 1. Data
- DFUC2021 labelled training set after exact-duplicate removal by MD5: **5,955 RGB images, 224×224**.
- Class counts: NONE 2,552, INFECTION 2,555, ISCHAEMIA 227, BOTH 621.
- No patient or case identifiers exist in the dataset.

## 2. Near-duplicate audit (reported only, not used for splitting)
- **Hash and grouping.** 64-bit perceptual hash (`imagehash.phash`, hash_size = 8), with complete-linkage grouping at T = 8 bits. T is the largest distance at which, for every distance ≤ T, the share of cross-class image pairs is ≤ 10% (unrelated pairs: 62.0%).
- **Groups found:** 5,799 groups. 146 of them have 2–3 images (302 images in total). 10 groups contain images released with different labels.
- **Effect on the split in section 3:**
  - 39 of the 1,191 test images have a near-duplicate in the training set (NONE 6, INFECTION 17, ISCHAEMIA 9, BOTH 7).
  - 41 of the 1,191 validation images have a near-duplicate in the training set.

## 3. Split
- **Method:** stratified random split at image level, 60:20:20. `train_test_split(test_size=0.20, stratify=label, random_state=42)`, then `test_size=0.25` of the remainder for validation. Rows are ordered by (label, filename) before splitting.

  | Class | Train | Validation | Test |
  |---|---|---|---|
  | NONE | 1,531 | 511 | 510 |
  | INFECTION | 1,533 | 511 | 511 |
  | ISCHAEMIA | 136 | 45 | 46 |
  | BOTH | 373 | 124 | 124 |
  | **Total** | **3,573** | **1,191** | **1,191** |

- 0 images and 0 MD5 hashes are shared between subsets. `group_id` is one id per image (no grouping).
- **Frozen file MD5s:** train.csv `2a7f9227b2b01baebfaf1754aad5f858`, validation.csv `8887c3731d4f3e3fe2012f69aa540110`, test.csv `4696e71f7e2934a2818dd8fe5104639e`.

## 4. Models
Both models are trained with seeds 42, 43 and 44, using the identical recipe.

| Model | Architecture |
|---|---|
| **MEFF expert** | DenseNet-169 (ImageNet) → CCDGS → Triplet Attention → SE → GAP → concat 42-D handcrafted → Dropout 0.5 → FC 512 → ReLU → Dropout 0.5 → FC 4 |
| **DSG** (Dense-ShuffleGCANet re-implementation) | The same, without SE and without the handcrafted features |

The DSG design follows Ajay, Bisht, Karthik, *IEEE Access* 13 (2025), doi:10.1109/ACCESS.2024.3524549.

Component definitions, as implemented in `meff_v3.py`:
- **CCDGS:** 3×3 group conv (4 groups) → BN → ReLU → channel shuffle → 3×3 depth-wise conv → BN → ReLU → 1×1 conv → BN, plus a residual connection. Spatial maps are preserved.
- **Triplet Attention:** Misra et al., WACV 2021. Three branches (C–H, C–W, H–W) with Z-pool → 7×7 conv → BN → sigmoid, averaged.
- **SE:** squeeze-and-excitation, reduction 16.
- **Handcrafted 42-D features**, computed on the original RGB image and standardised with training-set mean and SD only:
  - LBP, uniform, P = 8, R = 1, 10 bins
  - RGB histogram, 8 bins per channel (24 values)
  - Edge-orientation histogram: Gaussian blur (5×5) and histogram equalisation; Canny with thresholds 0.66× and 1.33× the median; Sobel orientation at the edge pixels; 8 bins over [0, π). 38 of the 5,955 images have no edge pixels, so their edge block is all zeros.

## 5. Training recipe (identical for every run)

| Item | Setting |
|---|---|
| Optimiser | Adam, lr 5e-5, weight decay 1e-3 |
| Batch / epochs | Batch 32, at most 100 epochs |
| Early stopping | Patience 15 on validation macro-F1 |
| LR schedule | ReduceLROnPlateau on validation macro-F1 (factor 0.5, patience 5, min 1e-7) |
| Loss | Focal loss, γ = 2, no α |
| Class balancing | WeightedRandomSampler with inverse class frequency |
| Train augmentation (label-independent) | RandomResizedCrop(224, 0.8–1.0), horizontal flip, vertical flip, rotation ±15°, ColorJitter(0.2, 0.2, 0.2, 0.02) |
| Val/test augmentation | None |
| Checkpoint selection | Best **validation macro-F1**; the best checkpoint is reloaded before prediction |
| Crashes / time limit | Resume from `last.pth`. Never re-run with a new seed. |

## 6. Evaluation
- **Ensembles:**
  - Primary: hard majority vote over the 3 seeds. On a 3-way tie, choose the class with the highest mean softmax probability.
  - Secondary: soft vote.
- **Primary metric:** test macro-F1.
- **Also reported:** accuracy, weighted-F1, macro-AUC (one-vs-rest), and per-class precision, recall, F1 and counts.
- **Primary comparison:** MEFF_hard vs DSG_hard.
- **Secondary comparisons:** MEFF_hard vs each DSG seed, and MEFF_hard vs the best single MEFF seed (chosen on validation macro-F1).
- **Statistics:** paired image-level bootstrap of Δ macro-F1 and Δ accuracy (resample test images; 2,000 resamples; seed 42). Exact McNemar test, with Holm correction across the 5 comparisons.

## 7. Decision rule (fixed now)
Based on the 95% bootstrap CI of Δ macro-F1 (MEFF_hard − DSG_hard):

| CI | Statement in the paper |
|---|---|
| Entirely above 0 | "MEFF outperforms Dense-ShuffleGCANet" |
| Entirely below 0 | "Dense-ShuffleGCANet outperforms MEFF" |
| Otherwise | "No significant difference between MEFF and Dense-ShuffleGCANet" |

The published DSG figures (86.09% accuracy, 85.77% F1) appear only in the literature table, with the footnote "different data split and training run; not directly comparable".

## 8. Limitations to state in the manuscript
1. "The split was performed at the image level. DFUC2021 contains several crops of the same wound; exact duplicates were removed by MD5 hashing, but near-duplicates were not separated. A perceptual-hash audit found that 39 of the 1,191 test images, including 9 of the 46 ISCHAEMIA images, have a near-duplicate in the training set, so absolute performance may be optimistic. Both models were trained and tested on the same split, so the comparison between them is not affected by this choice."
2. "Ten near-duplicate groups contain images with different released labels; labels were used as released."
3. "Results come from a single 60:20:20 split with three training seeds per model; no external test set was used."
